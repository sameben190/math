Limits

📖 What is a Limit?

A limit asks: "What value does a function approach as x gets closer and closer to some number?" We do NOT necessarily plug x in — we watch the behaviour as x approaches.

Written as: lim(x → a) f(x) = L means: as x gets infinitely close to a, f(x) gets infinitely close to L.

Key rule: For a limit to exist, the left-hand limit must equal the right-hand limit.

📐 Important Limit Facts

Standard Limits lim(x→0) sin(x)/x = 1
lim(x→∞) (1/n) = 0
lim(x→∞) r^x = 0 (if |r| < 1)
lim(x→0) sin(1/x) = does NOT exist (oscillates wildly)
lim(x→0+) arctan(1/x) = π/2
lim(x→0-) arctan(1/x) = -π/2

L'Hôpital's Rule: If you get 0/0 or ∞/∞, differentiate top and bottom separately, then take the limit.

lim f(x)/g(x) = lim f'(x)/g'(x) (when 0/0 or ∞/∞ form)

Series expansion of e^x: Used when direct substitution gives 0/0.

e^x = 1 + x + x²/2! + x³/3! + ...
e^(2x) = 1 + 2x + (2x)²/2! + (2x)³/3! + ... = 1 + 2x + 2x² + (4x³/3) + ...

Total Differentials

📖 What is a Total Differential?

If z = f(x, y), the total differential dz tells you the small change in z when BOTH x and y change by small amounts dx and dy.

Total Differential Formula dz = (∂z/∂x)dx + (∂z/∂y)dy

∂z/∂x means: differentiate z with respect to x while treating y as a constant.

∂z/∂y means: differentiate z with respect to y while treating x as a constant.

For three variables z = f(x,y,z): dz = (∂f/∂x)dx + (∂f/∂y)dy + (∂f/∂z)dz

1
Find ∂z/∂x: treat y as constant. d(3x)/dx = 3, so ∂z/∂x = 3
2
Find ∂z/∂y: treat x as constant. d(5y)/dy = 5, so ∂z/∂y = 5
3
Apply formula: dz = 3dx + 5dy
dz = 3dx + 5dy
IMG2 · Q17

1
∂k/∂x = 1, ∂k/∂y = 1, ∂k/∂z = 1

Exact Differentials — Finding z

📖 The Concept

If we are given dz = M dx + N dy, and told it is an exact differential, we want to recover the original function z.

Exactness condition: dz is exact if and only if:

∂M/∂y = ∂N/∂x

This must be verified first! If it's true, the differential is exact and z exists.

📐 Method to Find z from dz = M dx + N dy

Step-by-Step Method Step 1: Verify ∂M/∂y = ∂N/∂x (exactness check)
Step 2: Integrate M with respect to x: z = ∫M dx + g(y)
Step 3: Differentiate result with respect to y and set = N
Step 4: Solve for g'(y), then integrate to get g(y)
Step 5: Write final z
IMG1 · Q12
Given dz = (y + x)dx + (x + y)dy is exact, find z.
1
M = y + x, N = x + y. Check: ∂M/∂y = 1, ∂N/∂x = 1. ✓ Exact!
2
Integrate M with respect to x: z = ∫(y + x)dx = xy + x²/2 + g(y) (y is treated as constant, g(y) replaces the unknown function of y)
3
Differentiate z with respect to y and set equal to N: ∂z/∂y = x + g'(y) = x + y → g'(y) = y
4
Integrate: g(y) = y²/2
z = xy + x²/2 + y²/2
IMG3 · Q4
Given dz = (2y + 2x)dx + (2x + 2y)dy is exact, find z.
1
M = 2y + 2x, N = 2x + 2y. Check: ∂M/∂y = 2, ∂N/∂x = 2. ✓ Exact!
2
z = ∫(2y + 2x)dx = 2xy + x² + g(y)
3
∂z/∂y = 2x + g'(y) = 2x + 2y → g'(y) = 2y → g(y) = y²
z = x² + 2xy + y² (Note: this is (x + y)²)
IMG3 · Q5
Given dz = 2dx + 2e^(2y)dy is exact, find z.
1
M = 2 (no y), N = 2e^(2y) (no x). Check: ∂M/∂y = 0, ∂N/∂x = 0. ✓ Exact!
2
z = ∫2 dx = 2x + g(y)
3
∂z/∂y = g'(y) = 2e^(2y) → g(y) = e^(2y)
z = 2x + e^(2y)
IMG3 · Q6
Given dz = (6y² + 2)dx + (12xy + 6y)dy is exact, find z.
1
M = 6y²+2, N = 12xy+6y. Check: ∂M/∂y = 12y, ∂N/∂x = 12y. ✓ Exact!
2

∂z/∂y = 12xy + g'(y) = 12xy + 6y → g'(y) = 6y → g(y) = 3y²

Line Integrals

📖 What is a Line Integral?

A line integral integrates a function along a specific path (curve) in the xy-plane. Instead of integrating over an interval, you integrate along a route from point A to point B.

Line Integral Formula I = ∫[path] M dx + N dy

How to evaluate:
1. Parameterise the path (express x and y in terms of one variable)
2. Substitute into the integral and evaluate

Along a vertical line x = constant: dx = 0, so M dx vanishes!

Along a horizontal line y = constant: dy = 0, so N dy vanishes!

Along a curve y = f(x): Express dy = f'(x)dx and substitute.

IMG1 · Q13
Evaluate I = ∫(2x + y)dx + (3x − 2y)dy along the line from O(0,0) to A(0,4).
1
The path goes from (0,0) to (0,4). Both points have x = 0. So this is a vertical line along the y-axis, where x = 0 throughout.
2
Since x = 0 everywhere on this path: dx = 0, and x = 0.
3
Substitute: M dx = (2(0) + y)(0) = 0. The M dx term vanishes entirely.
4
Remaining integral: I = ∫(3(0) − 2y)dy = ∫(−2y)dy, y from 0 to 4.
5
I = [−y²]₀⁴ = −(4²) + 0 = −16
I = −16

Matrix Operations

📖 Basic Matrix Concepts

A matrix is a rectangular array of numbers arranged in rows and columns. We call an m×n matrix one with m rows and n columns.

Transpose Aᵀ Flip rows and columns.
Row i becomes column i.

If A = [a b] then Aᵀ = [a c]
        [c d] [b d]
2×2 Determinant |a b| = ad − bc
|c d|

Multiply diagonals, subtract.
3×3 Determinant — Cofactor Expansion along Row 1 |a b c|
|d e f| = a(ei − fh) − b(di − fg) + c(dh − eg)
|g h i|

Pattern of signs: + − + / − + − / + − +
Matrix Addition / Subtraction Add or subtract corresponding elements.
Matrices must have the SAME dimensions!

[a b] + [e f] = [a+e b+f]
[c d] [g h] [c+g d+h]

Matrix Inverse & Solving Systems

📖 What is the Inverse?

The inverse A⁻¹ of a matrix A satisfies: A × A⁻¹ = I (identity matrix).

The inverse is used to solve systems of equations: AX = B → X = A⁻¹B

Key rule: If det(A) = 0, the inverse does NOT exist! The system has no unique solution.

📐 Method: Adjugate/Cofactor Method

Formula A⁻¹ = (1/det(A)) × adj(A)

where adj(A) = transpose of the cofactor matrix

Cofactor C_ij = (−1)^(i+j) × M_ij
M_ij = determinant of the (n−1)×(n−1) matrix formed by
deleting row i and column j from A.

Sign pattern for 3×3 cofactors:

+ − +
− + −
+ − +

Symmetric & Skew-Symmetric Matrices

📖 Definitions

Symmetric matrix: Aᵀ = A (it equals its own transpose). The main diagonal is a mirror.

Skew-symmetric matrix: Aᵀ = −A. The diagonal entries are all zero, and off-diagonal elements are negatives of each other.

Decomposition Formula ANY matrix A can be split into symmetric (S) + skew-symmetric (K) parts:

S = (A + Aᵀ) / 2 ← symmetric part
K = (A − Aᵀ) / 2 ← skew-symmetric part

So: A = S + K

Coordinate Systems

📖 Three Coordinate Systems

We can describe any point in 3D space using three different systems:

Cartesian (x, y, z) Standard x,y,z axes.
You already know this one.
Cylindrical (ρ, φ, z) ρ = distance from z-axis
φ = angle from x-axis (in xy-plane)
z = height (same as Cartesian z)

FROM Cartesian:
ρ = √(x² + y²)
φ = arctan(y/x)
z = z

TO Cartesian:
x = ρ cos φ
y = ρ sin φ
z = z
Spherical (r, θ, φ) r = distance from origin
θ = angle from z-axis (polar)
φ = angle from x-axis (azimuthal)

TO Cylindrical:
ρ = r sin θ
φ = φ (same angle!)
z = r cos θ

TO Cartesian:
x = r sin θ cos φ
y = r sin θ sin φ
z = r cos θ

Area Between Curves

📖 The Method

When two curves enclose an area, we integrate the difference of the top curve minus the bottom curve:

Area Between Curves Formula Area = ∫[a to b] [f_top(x) − f_bottom(x)] dx

Step 1: Find intersection points (set the curves equal, solve for x)
Step 2: Determine which curve is on top
Step 3: Integrate (top − bottom) from left to right intersection
IMG1 · Q7
Find the area enclosed by y = x² and y = 8x.
1
Find intersections: x² = 8x → x² − 8x = 0 → x(x − 8) = 0
So x = 0 and x = 8.
2
Which is on top? Test x = 4: y=8(4)=32, y=4²=16. So y = 8x is on top.
3
Area = ∫₀⁸ (8x − x²) dx = [4x² − x³/3]₀⁸
4
= 4(64) − 512/3 = 256 − 170.67 = 256/3
Area = 256/3 ≈ 85.33 square units

Test x = 1: y=4(1)=4 vs y=2(1)²=2. So y = 4x is on top.
3
Area = ∫₀² (4x − 2x²) dx = [2x² − (2x³)/3]₀²
4
= [2(4) − 2(8)/3] − 0 = 8 − 16/3 = 24/3 − 16/3 = 8/3
Area = 8/3 ≈ 2.67 square units

Velocity & Acceleration Vectors

📖 The Connection

If a particle's position is given as a vector function r(t), then:

Vector Calculus of Motion Position: r(t) = x(t)î + y(t)ĵ + z(t)k̂

Velocity: v(t) = dr/dt = x'(t)î + y'(t)ĵ + z'(t)k̂

Acceleration: a(t) = dv/dt = x''(t)î + y''(t)ĵ + z''(t)k̂

Just differentiate each component with respect to t. î, ĵ, k̂ are fixed unit vectors so they stay as-is.

Acceleration = dv/dt:
d(3t²−4)/dt = 6t
d(4t)/dt = 4
d(1)/dt = 0

a(t) = 6tî + 4ĵ
v(t) = (3t² − 4)î + 4tĵ + k̂   |   a(t) = 6tî + 4ĵ

Ordinary Differential Equations (ODE) Applications

📖 The Big Idea

Many real-world problems describe how something changes over time. The rate of change is the derivative. When we write that down as an equation, we get an ODE. Solving it means finding the original function.

Separation of Variables — the Basic Technique If dy/dt = k·y (rate proportional to amount), then:

Rearrange: dy/y = k dt
Integrate both sides: ln|y| = kt + C
Exponentiate: y = Ae^(kt) where A = e^C

Apply initial condition to find A.
First-Order Linear ODE dy/dt + P(t)·y = Q(t)

Step 1: Compute integrating factor: μ = e^(∫P dt)
Step 2: Multiply both sides by μ
Step 3: Left side becomes d(μy)/dt
Step 4: Integrate both sides: μy = ∫μQ dt + C
Step 5: Solve for y
Second-Order ODE: Spring-Mass m·x'' + kx = 0

Divide by m: x'' + (k/m)x = 0
Let ω² = k/m (natural frequency)
Characteristic equation: r² + ω² = 0 → r = ±ωi

General solution: x(t) = A cos(ωt) + B sin(ωt)
IMG1 · Q3
Population P grows proportional to its size. P(0) = P₀, growth rate = k. Find P(t).
1
"Grows proportional to its size" means: dP/dt = kP
2
Separate: dP/P = k dt. Integrate: ln|P| = kt + C → P = Ae^(kt)
3
Apply P(0) = P₀: P₀ = Ae⁰ = A. So A = P₀.
P(t) = P₀ · e^(kt)
IMG2 · Q23 / IMG6 · Q24
A radioactive substance decays at a rate proportional to its mass. Initial mass M₀, decay constant k. Find M(t).
1
"Decays proportional to mass" means: dM/dt = −kM (negative because it's decreasing!)
2
Same form as population but negative k:
dM/M = −k dt → ln|M| = −kt + C → M = Ae^(−kt)
3
M(0) = M₀ → A = M₀
M(t) = M₀ · e^(−kt)
IMG2 · Q20
A metal bar at temperature T₀ is in environment at temperature Tᵣ. Heat loss follows dT/dt = −h(T − Tᵣ). Find T(t).
1
Let u = T − Tᵣ (temperature difference). Then du/dt = dT/dt = −hu.
2
This is the same decay equation! u = u₀ · e^(−ht).
At t=0: u₀ = T₀ − Tᵣ.
3
T − Tᵣ = (T₀ − Tᵣ)e^(−ht) → T = Tᵣ + (T₀ − Tᵣ)e^(−ht)
T(t) = Tᵣ + (T₀ − Tᵣ) · e^(−ht)
IMG2 · Q21
A 100 L tank has 10 kg salt. Water with 0.5 kg/L enters at 5 L/min; well-mixed solution leaves at 5 L/min. Find S(t).
1
Since inflow rate = outflow rate = 5 L/min, volume stays constant at 100 L.
2
Rate in = 0.5 × 5 = 2.5 kg/min
Rate out = (S/100) × 5 = S/20 kg/min
dS/dt = 2.5 − S/20
3
Rearrange: dS/dt + S/20 = 2.5 → First-order linear ODE.
Integrating factor: μ = e^(∫1/20 dt) = e^(t/20)
4
Multiply: d(Se^(t/20))/dt = 2.5e^(t/20)
Integrate: Se^(t/20) = 50e^(t/20) + C
Divide: S = 50 + Ce^(−t/20)
5
Apply S(0) = 10: 10 = 50 + C → C = −40
S(t) = 50 − 40e^(−t/20) kg
As t → ∞, S → 50 kg. This is the steady state: tank fills to 0.5 kg/L × 100 L = 50 kg. Makes sense!

A 25 L brine tank has 2.5 kg salt. Fresh water (0 kg/L) enters at 1.5 L/min; solution drains at 1.5 L/min. Find salt concentration over time.

A mass m on a spring: m·d²x/dt² + kx = 0. Find the displacement x(t).

A damped harmonic oscillator: m·d²x/dt² + c·dx/dt + kx = 0. Find x(t) for overdamped case.

A rod of length L has insulated sides. ∂u/∂t = k·∂²u/∂x². Find the steady-state temperature distribution.
1

2

4
A and B come from boundary conditions (the temperatures at x=0 and x=L).

Differentiation Rules

📖 The Key Rules

Product Rule If y = u·v, then:
y' = u'v + uv'

Think: "first·deriv_second + second·deriv_first"
Quotient Rule If y = u/v, then:
y' = (u'v − uv') / v²

Think: "lo·d(hi) − hi·d(lo) all over lo²"
Chain Rule If y = f(g(x)), then y' = f'(g(x)) · g'(x)

Example: d/dx[(x²+1)^n] = n(x²+1)^(n−1) · 2x
Key Derivatives to Know d/dx[eˣ] = eˣ    d/dx[e^(kx)] = ke^(kx)
d/dx[ln x] = 1/x    d/dx[xⁿ] = nxⁿ⁻¹
d/dx[sin x] = cos x    d/dx[cos x] = −sin x
IMG5 · Derivative of x² ln x (Product Rule)

Let u = x², v = ln x. Then u' = 2x, v' = 1/x.

d/dx[x² ln x] = 2x ln x + x = x(2 ln x + 1)

Directional Derivatives & Gradient

📖 What is a Directional Derivative?

Imagine standing on a hill. The slope depends on which direction you walk. The directional derivative measures the slope of f in any specific direction.

The gradient ∇f is a vector pointing in the direction of steepest ascent.

Gradient ∇f = (∂f/∂x)î + (∂f/∂y)ĵ (in 2D)
∇f = (∂f/∂x)î + (∂f/∂y)ĵ + (∂f/∂z)k̂ (in 3D)

The gradient points in the direction of maximum increase.
Maximum Directional Derivative Max directional derivative = |∇f| = √[(∂f/∂x)² + (∂f/∂y)²]

This maximum occurs in the direction of ∇f itself.
IMG4 · Q4
Find the maximum directional derivative of f(x,y) = 5x² − 2y² at (1, −1).
1
Compute the gradient components:
∂f/∂x = 10x    ∂f/∂y = −4y
2
Evaluate at (1, −1):
∂f/∂x = 10(1) = 10
∂f/∂y = −4(−1) = 4
3
Gradient vector at (1,−1): ∇f = 10î + 4ĵ
4
Maximum directional derivative = |∇f| = √(10² + 4²) = √(100 + 16) = √116 = 2√29
Max directional derivative = 2√29 ≈ 10.77, in the direction (10î + 4ĵ)

Q19: Use chain rule. Let u = x²+y²+z². Then f = ln u, ∂f/∂u = 1/u, ∂u/∂y = 2y.
∂f/∂y = (1/u)(2y) = 2y/(x²+y²+z²)

∂f/∂y = 4u³ · 2y = 8y(x²+y²+z²)³
Q19: ∂f/∂y = 2y/(x²+y²+z²)    Q20: ∂f/∂y = 8y(x²+y²+z²)³
